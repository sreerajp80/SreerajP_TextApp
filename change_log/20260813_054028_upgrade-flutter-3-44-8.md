**Plan:** [plans/20260813_053747_upgrade-flutter-3-44-8.md](../plans/20260813_053747_upgrade-flutter-3-44-8.md)

## Why

The installed toolchain moved to Flutter 3.44.8 (stable, 2026-07-23) with Dart 3.12.2, but
the project still declared Flutter 3.41.9 / Dart 3.11.5 as its minimum.

## What changed

### Config

- `pubspec.yaml`
  - `environment.sdk`: `^3.11.5` → `^3.12.2`
  - `environment.flutter`: `">=3.41.9"` → `">=3.44.8"`
- `pubspec.lock` — regenerated by `flutter pub get`. Only the `sdks:` block moved
  (`dart: ">=3.12.2 <4.0.0"`, `flutter: ">=3.44.8"`). **No package version changed.**

### Docs (stack statements only)

  them is a separate change.

## Open item — new lint after the upgrade

The newer analyzer turns on **`prefer_initializing_formals`**. It reports **54 info-level
hints**, all the same shape: a constructor that takes a parameter and then assigns it to a
field in the body, where `this._field` in the parameter list would do.

Files affected: the five `*_document_session.dart` files (txt, markdown, json, csv-adjacent,
xml), `json_exporter.dart`, `xml_exporter.dart`, and `sync_provider.dart`.

Nothing is broken — these are style hints, not errors, and the build and tests are clean.
Fixing them was outside this plan's scope, so it was **not** done and is left for the user
to decide.
