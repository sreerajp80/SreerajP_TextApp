# Change log — Help topics for QR sharing, backup, and search

**Plan:** `plans/20260813_174400_help_topics_qr_backup_search.md`

## What changed

Added three new help topics to the Help section in Settings, alongside the
existing "Split array" topic. The new topics are:

1. **QR sharing** — explains how the AirQR optical air-gap transfer works
   (sending, receiving, session code encryption, speed expectations).
2. **Backup & export** — explains how to keep copies of files via the Export and
   Save a copy features and where to store backups safely.
3. **Search** — explains the two search layers: in-document find & replace
   (case, whole-word, regex) and workspace-wide search (local index, format
   filters, on-device only).
